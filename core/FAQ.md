# FAQ

### Как обновить бд:
1. сделать локальный сервер postgres хоть через докер хоть просто для винды - похуй
2. в файле `.env.alembic` поправить под себя всю информацию
3. почистить схему public свой бд чтобы конфликтов имен не было
4. выполнить команду 
```sh
alembic upgrade head
```
ну и в целом посмотри как работать с `alembic`
