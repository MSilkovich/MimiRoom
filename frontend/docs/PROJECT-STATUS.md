# Текущий статус

Frontend 0.5.0 подключён к обновлённой спецификации MimiRoom/core v0.0.1. Реализованы серверные слоты, создание/отмена/завершение записей, профиль, история питомца, мастера, услуги, графики и роли.

Демо работает без backend. Live требует доступного core и его базы данных. [Подробные изменения](FRONTEND-UPDATE.md), [границы контракта](BACKEND-NEXT.md), [запуск](../README.md).
