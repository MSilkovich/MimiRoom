# MimiRoom

Монорепозиторий студии МиМиРум: `core/` — API, `tg/` — Telegram, `engine/` — AI, `frontend/` — клиентское приложение и CRM команды.

## Фронтенд локально

Нужен Node.js 22+. Из корня репозитория:

```sh
cd frontend
npm ci
npm start
```

Клиенты: http://127.0.0.1:4180/client/ · Команда: http://127.0.0.1:4180/studio/

Без подключения доступен деморежим. Для работы с настоящими данными запустите core по его инструкции, откройте вход и используйте учётную запись API. По умолчанию фронтенд проксирует запросы на `http://127.0.0.1:30010`. Другой адрес задаётся через `CORE_API_URL` в `frontend/.env.local`. Секреты в Git не добавляются.

[Подробный запуск](frontend/README.md) · [Контракт API](frontend/docs/openapi.json) · [Изменения фронтенда](frontend/docs/FRONTEND-UPDATE.md)

Существующие сервисы и Docker-конфигурация находятся в своих каталогах. Фронтенд не запускает PostgreSQL, Redis и core автоматически.
